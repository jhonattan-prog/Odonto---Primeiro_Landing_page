# Dra. Mariana Lins | Odontologia Digital Premium

Landing Page responsiva e de alto padrão desenvolvida para a clínica odontológica **Dra. Mariana Lins**. O projeto foi estruturado com foco em credibilidade, tecnologia, conforto do paciente (atendimento humanizado) e excelente desempenho.

---

## 🚀 Funcionalidades

A página é dividida em seções estratégicas de conversão:
- **Hero**: Apresentação principal marcante com botões de chamada para ação (CTA) para agendamento.
- **Serviços**: Grade interativa contendo 6 especialidades clínicas de alto padrão (Lentes de Contato, Alinhadores Invisíveis, Harmonização, Reabilitação, Clareamento a Laser e Check-up Preventivo).
- **Sobre**: Biografia da cirurgiã-dentista destacando sua expertise de mais de 12 anos e atendimento confortável.
- **Depoimentos**: Feedback real de pacientes destacando resultados estéticos e tratamentos sem dor.
- **Rodapé**: Informações de contato direto (WhatsApp, telefone, endereço físico) e horários de funcionamento.

---

## 🛠️ Tecnologias Utilizadas

- **Estrutura**: HTML5 semântico com otimizações para mecanismos de busca (SEO).
- **Estilização**: CSS3 Moderno (Custom Properties, CSS Grid, Flexbox, Animações customizadas).
- **Ícones**: Desenhados nativamente em SVG inline para garantir segurança (sem carregar scripts externos de terceiros) e alta fidelidade visual.
- **Servidor Estático**: Módulo `serve` para rodar e visualizar o site localmente com segurança.

---

## 💻 Como Rodar o Projeto Localmente

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

1. Clone o repositório ou faça o download da pasta do projeto.
2. No diretório raiz do projeto, instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Abra o navegador no endereço indicado (geralmente [http://localhost:3000](http://localhost:3000)).

## 🌐 Publicação no GitHub (Instruções)

Para conectar este projeto ao repositório remoto que você criou no GitHub, abra o terminal no diretório do projeto e execute os seguintes comandos:

```bash
# 1. Inicializa o Git no diretório local (se não estiver inicializado)
git init

# 2. Adiciona todos os arquivos ao versionamento (respeitando o .gitignore)
git add .

# 3. Cria o primeiro commit
git commit -m "initial commit: estrutura da landing page odontológica premium"

# 4. Vincula o repositório local ao remoto no GitHub
git remote add origin https://github.com/jhonattan-prog/Fono---Primeiro_Landing_page.git

# 5. Define a branch principal como 'main'
git branch -M main

# 6. Envia o código para o GitHub
git push -u origin main
```
